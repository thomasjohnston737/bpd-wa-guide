## Branch rules for agents (by Github COORDINATOR)

1. Name every branch with your agent name and a short task, e.g. `cursor/fix-login`, `codex/retention-days`, `claude/race-import`.
2. Keep at most 2 open branches per repo. Finish or close one before starting another.
3. One task per branch. Don't reuse old branches for new work.
4. Never merge anything into any repo without Tom's explicit OK.
5. If a PR is closed without merging, delete its branch straight away. Merged branches are deleted automatically by GitHub.
6. Never push straight to the default branch, and never delete a branch you didn't create.
7. If a branch has had no commits for 14 days, tell Tom, then delete it or open a PR.
